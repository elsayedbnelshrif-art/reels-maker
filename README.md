# reels-maker

بيعمل ريلز عربي (9:16) أوتوماتيك باستخدام [MoneyPrinterTurbo](https://github.com/harry0703/MoneyPrinterTurbo) على GitHub Actions، ببلاش.

## أول مرة بس
ضيف مفتاح Pixabay:
Settings ← Secrets and variables ← Actions ← New repository secret
- Name: `PIXABAY_API_KEY`
- Secret: المفتاح من https://pixabay.com/api/docs/

## تعمل ريل
1. افتح تبويب **Actions** ← اختار **اعمل ريل - Make Reel** من الشمال.
2. دوس **Run workflow**.
3. اكتب النص العربي، وكلمات البحث بالإنجليزي، واختار الصوت ← **Run workflow**.
4. استنى 5–10 دقايق لحد ما تبقى العلامة خضرا ✅.
5. ادخل على الـ Run، هتلاقي فوق لينك **Download reel** — أو افتح فرع `videos` في الـ Repo، الفيديوهات كلها في فولدر `reels`.
